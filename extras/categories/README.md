# Category artwork

Ten 560×315 JPEGs for skin 1.12.70. OpenAI imagegen created the original
cinematic cards and the unbranded blue Disney background on 2026-11-07.
No fal generation was charged. Service names and category keys stay in the
provider; the skin renders these full-image cards without a text overlay.

The Disney wordmark uses the official press asset, composited in white over the
original generated background. Source: https://press.disneyplus.com/about/disney-plus-logo-2024
Original asset: https://lumiere-a.akamaihd.net/v1/images/a8e5567d1658de062d95d079ebf536b0_4096x2309_6dedcc02.png
The image service refused the branded Disney generation, so the existing logo
system was extended with the official asset instead of a generated imitation.

All cards keep safe central wordmarks and use a dark base with a distinct luminous
accent. Generated originals remain in the session image archive; deployment
contains only display-size JPEGs (391,702 bytes total). Decoded RGBA pixels for all
ten cost about 6.73 MiB before Kodi texture overhead. Live residency belongs to
the AM9 acceptance receipt; this arithmetic is not an appliance measurement.
